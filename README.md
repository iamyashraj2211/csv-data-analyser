📊 CSV Data Analyser

A beginner-friendly data analysis web application built with Python, Pandas, and Streamlit. It allows users to upload CSV files, preview datasets, and explore useful information through an interactive dashboard.

🚀 Features

CSV File Upload: Upload datasets in CSV format.

Data Preview: View the first few rows of an uploaded dataset.

Dataset Summary: Calculate the total number of rows, columns, and missing values.

Column Names: Display all column names in the dataset.

Data Types: Inspect the data type of each column.

Column Information: View data types, missing-value counts, and unique-value counts for each column.

Interactive Dashboard: Explore dataset information through a simple Streamlit interface.
